# NHL-GM-and-HC-hirings
An analysis of NHL general manager and head coach hirings since the 2004-05 NHL lockout. The syntax files downloads historic season-by-season records of NHL general manager (GM) and head coach (HC) from [NHL Records](https://records.nhl.com), links GMs and HCs together who have worked together, and analyzes patterns in GMs hiring of HCs in the 20 seasons since the 2004-05 lockout.

To replicate the analysis, run the files in the syntax file in order i.e., run the file named '01.R' first, run the file named '02.R' second, etc.
